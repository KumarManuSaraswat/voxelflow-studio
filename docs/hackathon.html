01 / Get ready

Set up before your slot.

  1. Extract the entire kit. Install Node.js 22+ and Blockbench desktop 5.2+ beforehand.
  2. Load plugins/voxelflow-studio/blockbench/voxelflow_studio.js through Blockbench → File → Plugins → Load Plugin from File.
  3. Open Start Companion.cmd, then Tools → VoxelFlow Studio → Connect in Blockbench. Keep the companion running.
  4. Install/refresh VoxelFlow {{VERSION}} in your supported local host. Start a fresh chat and verify that create_prop is available. See full installation instructions.
  5. Open Check Setup.cmd. Expect four PASS results. Rehearse one actual prompt in your AI host and approve its tool request if asked.

The checker verifies the package and connection. It does not test AI account access or language understanding. Node.js, Blockbench, and your AI-host login are not bundled.

03 / Copy this brief

Build something beyond a preset.

Use VoxelFlow Studio. First check the live editor. Create a Minecraft-style brass festival lantern, about 18 pixels tall, with a dark metal base and four corner posts, amber glass panels, a gold top cap, and a square carrying handle. Keep it under 24 editable cubes and group related parts. Use the general prop tool, not the robot preset. Amber is a flat color, not a real light effect. Use lowercase underscore identifiers for model, material, part, and group names. Explain the design, submit once, and wait for my approval in Blockbench. Only report completion after get_operation says applied.

After approving in Blockbench

“I approved the creation. Check the operation, inspect the actual model, and validate it. Do not create another copy.”

Refine and export

“Inspect the material names. Change only the amber panels to blue (#4AA8E8). Wait for my approval.” Then: “Validate, propose a Bedrock resource asset export, and wait for my approval and Save dialog.”

05 / Be precise

A desktop beta with clear limits.

Full ChatGPT account onboarding and public-directory approval remain outstanding. Demonstrate the local host you have rehearsed. Props support up to 128 cubes and 16 colors; animated robots use a separate preset. Exports contain resource assets and editable source. Item registration, wearable behavior, real lighting, and Minecraft runtime testing are separate work.

If disconnected, reuse one running companion and reconnect. If a request is pending, approve it once and check its operation. Never paste the connection file or token into chat. If internet fails, show the saved models and say so.
