# VoxelFlow Studio 0.3.1 — Desktop beta

Turn a prompt into an editable Minecraft-style prop in Blockbench, with native review, texture editing, Undo, validation, and resource exports. The release also includes the Atlas robot and its editable idle/walk/attack animations.

This patch corrects dependency-lock entries changed during the 0.3.0 version update. A clean source installation now uses the original dependency versions. The earlier tag is retained for history; its release workflow stopped before publishing assets.

## Choose a download

- **voxelflow-desktop-beta-0.3.1.zip** — recommended for artists. Includes the local marketplace catalog, plugin, bundled MCP server, setup/modeling skills, and Windows launcher. No npm install or build step.
- **voxelflow-plugin-0.3.1.zip** — portable plugin package for import/submission tooling.
- **voxelflow-studio-0.3.1.zip** — complete source/build package, examples, and contributor documentation. Developers run `npm ci` after extracting.
- **DESKTOP-SHA256SUMS.txt / SHA256SUMS.txt** — checksums for the corresponding artifacts.

Requires Node.js 22+, Blockbench desktop 5.2+, and a ChatGPT/Codex desktop host supporting local execution. Follow the [installation guide](https://github.com/KumarManuSaraswat/voxelflow-studio/blob/v0.3.1/plugins/voxelflow-studio/INSTALL.md).

## Verified scope

84 automated tests, type checking, build, generated examples, and fresh-extraction desktop verification passed locally. Actual Blockbench 5.2.2 modeling, recoloring, Undo, native source roundtrip, and export were exercised on Windows. Evidence and its limits are recorded in [verification](https://github.com/KumarManuSaraswat/voxelflow-studio/blob/v0.3.1/docs/verification.md). Release automation runs the automated checks again before publishing assets.

## Known limits

This is a local desktop beta, not an approved public ChatGPT directory listing. Autonomous ChatGPT natural-language use, macOS/Linux, and Minecraft runtime behavior remain unverified. MCP geometry revisions create a new tab. Custom creature animation, inventory item/attachable configuration, and gameplay behavior are not included. Bedrock downloads are resource assets requiring further game integration.
