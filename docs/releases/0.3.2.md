# VoxelFlow Studio 0.3.2 — Desktop beta

This release fixes a blocker found during a real AI-host rehearsal: Codex rejected the tuple-style coordinate schema and hid `create_prop`. Coordinates now advertise a single numeric `items` schema with exactly three values. Numeric bounds, positive dimensions, approval, and all other validation remain enforced.

**Upgrade:** extract the full new desktop ZIP, refresh the VoxelFlow plugin in your host, and start a fresh local chat. Confirm `create_prop` is available before a live demonstration. Keep the companion running and connect Blockbench. Your host may require its own approval before the separate Blockbench approval.

## Downloads

- **voxelflow-desktop-beta-0.3.2.zip** — recommended artist installation; no npm install/build step.
- **voxelflow-hackathon-kit-0.3.2.zip** — desktop package plus a bundled setup checker, offline presenter page, one-/three-/five-minute scripts, editable examples, screenshots, and resource ZIPs. Extract everything and open START HERE.html.
- **voxelflow-plugin-0.3.2.zip** — portable plugin package for import/submission tooling.
- **voxelflow-studio-0.3.2.zip** — source/build package for contributors.

Requires Node.js 22+, Blockbench desktop 5.2+, and a host supporting local MCP plugins. Node.js, Blockbench, and an AI-host account are installed separately. [Installation](../../plugins/voxelflow-studio/INSTALL.md).

## Verification and limits

84 tests, type checking, builds, example validation, and fresh-extraction desktop verification pass. The regression assertion checks the schema the MCP server actually advertises. The kit's bundled checker was tested with a real connected Blockbench 5.2.2 editor. See [the verification record](../verification.md) for the exact live AI rehearsal result and its boundaries.

Full ChatGPT onboarding, public-directory approval, macOS/Linux, and Minecraft runtime behavior remain unverified. General props are static cube models; animated robots use a separate preset. Game item registration, wearable behavior, true emissive lighting, and behavior packs are separate integration work.
