# VoxelFlow Studio 0.3.4 — Token-efficient modeling

The assistant can describe repeated details once and let VoxelFlow build the copies locally. Every copy remains an ordinary editable Blockbench cube. Native approval, scene-change checks, Undo and export validation remain in place.

`inspect_project` now defaults to `detail: "summary"`. It returns cube/bone counts and group counts alongside the existing materials, rig mapping/detection, textures, animation summaries and unsupported-feature warnings. Consumers that need the former geometry representation must request `detail: "full"`; this preserves the bone transforms and prop part coordinates, pivots, rotations and UVs.

See [token-efficient modeling](https://github.com/KumarManuSaraswat/voxelflow-studio/blob/v0.3.4/docs/token-efficient-modeling.md) for the exact contract and reproducible measurements. Robot creation already uses a compact template; repeat applies to custom props.

## Updating

Update both the companion and the Blockbench plugin from the same 0.3.4 package. Restart the companion, reload the Blockbench plugin, reconnect, and refresh the chat host's tool discovery (or start a new chat). Existing 0.3.3 installations do not acquire these features automatically. Older explicit prop blueprints remain valid. There are still 14 tools and 2 prompts.

## Scope of verification

Automated tests compare generated geometry, validate expanded limits, exercise approval/retry behavior and use the official MCP SDK with a transport fixture. Package verification runs from a fresh extraction without node_modules. These checks do not establish live Blockbench visual quality or account-specific ChatGPT token billing. No fixed percentage of whole-chat token savings is promised.
