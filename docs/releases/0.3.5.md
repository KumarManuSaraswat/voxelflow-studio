# VoxelFlow Studio 0.3.5 — Individual part edits

Unreleased development build. Ask to move a pocket, widen a handle, or rotate a crystal without generating a replacement model. The new `edit_parts` tool updates existing cubes in the current Bedrock project. It supports translation, absolute bounds/rotation/cube pivots, and assigning an existing VoxelFlow prop material to selected cubes.

Every batch requires native approval, checks the exact project and part IDs, refuses changed scenes, and creates one Undo step. Geometry-only edits preserve per-face UVs and texture pixels. Material assignment deliberately replaces selected-face UVs. Box-UV resizing, adding/deleting cubes, meshes, and bone edits are outside this tool's scope.

Update both the Blockbench plugin and the companion/chat plugin, restart the companion, reload Blockbench's plugin, reconnect, and refresh tool discovery or start a fresh local chat. There are now 15 tools and 2 prompts. Existing 0.3.4 installations will not acquire the new tool automatically.

All 139 automated tests, type checking, build, examples, and fresh-extraction desktop verification pass. A live Blockbench smoke test moved only a bag's pocket, preserved the other parts and IDs, verified retry deduplication, and restored the original inspection with native Undo. See [verification](../verification.md) for coverage and limits, and [editing parts](../editing-parts.md) for prompts and the tool contract.
