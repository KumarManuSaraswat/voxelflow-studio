# VoxelFlow Studio 0.3.3 — Easier setup and contribution

This beta focuses on getting from a download to a first editable model.

- Windows users can launch **Start VoxelFlow.cmd** and **Check VoxelFlow.cmd** directly beside **START-HERE.md** in the extracted desktop-beta ZIP.
- Diagnostics are bundled with their dependencies. No npm install is needed. They check Node, package completeness, required MCP tools, and the local editor connection without changing the model or printing session credentials.
- Diagnostics preserve custom companion configuration and explicitly separate local editor readiness from chat permissions.
- The setup skill distinguishes missing chat tools from a disconnected editor, avoiding repeated Blockbench setup advice when a cloud chat lacks local execution.
- A prompt gallery includes six starter briefs and a recolor/validate/export workflow.
- New installation and showcase issue forms plus scoped contributor tasks welcome artists, testers, and documentation contributors.

## Upgrade

Extract the new desktop-beta ZIP into a permanent folder. Close the old companion before starting the new one. Reload the Blockbench plugin from the new folder, refresh or upgrade VoxelFlow in your local chat host, reconnect Blockbench, and start a fresh local chat. Keep saved models and exports. Do not copy or share bridge.json.

## Scope

This remains a local desktop beta. Windows is tested. Account-level ChatGPT onboarding, macOS/Linux, and Minecraft runtime behavior remain unverified. Geometry changes through MCP still create a new project tab; precise in-place editing is available through Blockbench. No cloud MCP service or public ChatGPT directory listing is included.
